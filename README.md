# Canada Engineer Portfolio

A minimal Next.js portfolio designed around engineering case studies and business impact.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What to customize first

1. Replace `Your Name`, GitHub, LinkedIn, and email in `app/page.tsx` and `components/site-header.tsx`.
2. Replace the example project in `lib/projects.ts` with a real project.
3. Never invent impact metrics. Use only numbers you can reasonably verify.
4. Add more projects by copying the object in `lib/projects.ts` and changing the slug/content.
5. Push the repository to GitHub and import/select it in Vercel.

## Recommended case study structure

- Context
- Problem
- Discovery
- Investigation
- Decisions / trade-offs
- Solution
- My contribution
- Results
- Business impact
- What I learned
